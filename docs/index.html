Long-running Mastra agent hosted in Coolify. Receives webhooks, decides action, spawns workers, processes callbacks. Creates GitHub PRs, updates Linear issues, posts triage findings as comments.

Ephemeral Container · Claude Code CLI

② Infrastructure
Sidecar · SQU-15
🔑 Token Refresh
Alpine container. Monitors OAuth credentials on shared volume. Refreshes tokens every 5 min before expiry. Atomic writes + flock.
claude-auth volume 30min buffer 3x retry
Network · Docker
🌐 pm-agent-net
Docker bridge network. PM agent reachable as http://pm-agent:3000. Workers callback over internal hostname. No external exposure.
container isolation AGENT_KEY auth
Hosting · SQU-13
☁️ Coolify + Traefik
Docker Compose deployment. Traefik handles HTTPS termination and routes domain to PM agent. Docker socket mounted for spawning.
docker.sock HTTPS healthchecks
③ End-to-End Flows
Coding Pipeline
① You move issue → "In Progress"
② Linear webhook → PM agent
③ PM agent spawns coding worker
④ Worker: clone → branch → claude -p → push
⑤ Worker callbacks with success + branch
⑥ PM agent creates PR via GitHub API
⑦ PM agent posts PR link to Linear
⑧ Linear status → "In Review"
⑨ You review & merge
Triage Pipeline (SQU-16 · Future)
① You create issue in Linear
② Linear webhook (created) → PM agent
③ PM agent spawns triage worker
④ Worker: clone → read CLAUDE.md → analyze
⑤ Worker callbacks with findings
⑥ PM agent posts analysis to Linear
⑦ Auto-sets estimate & priority
⑧ Flags unclear issues
⑨ Issue ready for "In Progress"
④ Shared Resources
Docker Volume
claude-auth
OAuth credentials shared between PM agent, token refresh sidecar, and all workers. Sidecar writes, workers read.
Host Bind Mount
SSH Keys (read-only)
Host SSH keys mounted into coding workers only. Enables git push to GitHub over SSH.
Environment
AGENT_KEY
Shared secret passed to workers at spawn. Required in x-agent-key header on all callbacks.
